Project Proposal: ระบบจดบัญชีรายรับรายจ่าย

1. รายชื่อสมาชิก
   1. จิรายุส ติ๊บปะสอน    รหัสนักศึกษา 1690700933
   2. ณัฐวรรธน์ พันธุ์ธรรม  รหัสนักศึกษา 1690700461

2. ชื่อโครงการ
   ระบบจดบัญชีรายรับรายจ่าย (Income-Expense Tracker)

3. รายละเอียดโครงการคร่าวๆ
   โปรแกรมภาษา Python ที่ทำงานผ่านเมนูบนหน้าจอ ช่วยให้ผู้ใช้จดรายรับรายจ่ายประจำวันและดูว่าเงินคงเหลือเท่าไร
   ข้อมูลทั้งหมดบันทึกลงไฟล์ข้อความ ปิดโปรแกรมแล้วเปิดใหม่ข้อมูลก็ยังอยู่

   โปรแกรมสามารถทำอะไรได้บ้าง
   1. เพิ่มรายการรายรับ เช่น เงินเดือน ค่าขนม โดยระบุวันที่ หมวดหมู่ และจำนวนเงิน
   2. เพิ่มรายการรายจ่าย เช่น ค่าอาหาร ค่าเดินทาง โดยระบุวันที่ หมวดหมู่ และจำนวนเงิน
   3. แสดงรายการทั้งหมดเป็นตารางที่อ่านง่าย พร้อมเลขลำดับ
   4. ลบรายการที่บันทึกผิด
   5. สรุปยอดรวมรายรับ ยอดรวมรายจ่าย และยอดเงินคงเหลือ
   6. สรุปรายจ่ายแยกตามหมวดหมู่ เพื่อดูว่าใช้เงินไปกับอะไรมากที่สุด
   7. ตรวจสอบข้อมูลที่กรอก เช่น จำนวนเงินต้องเป็นตัวเลขและมากกว่า 0 ถ้าผิดให้กรอกใหม่

4. ความรู้ที่นำมาใช้
   - input / print / f-string      : รับข้อมูลและแสดงผลเป็นตาราง
   - if / elif / else              : ตรวจสอบเมนูและข้อมูลที่กรอก
   - while loop                    : วนเมนูจนกว่าผู้ใช้เลือกออกจากโปรแกรม
   - for loop                      : แสดงรายการและรวมยอด
   - list / tuple                  : เก็บรายการรายรับรายจ่ายในหน่วยความจำ
   - อ่าน/เขียนไฟล์ข้อความ          : บันทึกและโหลดข้อมูลบัญชี
